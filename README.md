  Todo List App
A simple todo-list application built as a learning project to practice connecting a frontend, backend, and database into one working app.

  Tech Stack
Frontend: HTML, CSS
Backend: C# (ASP.NET Core)
Database: SQL

  📌 Status
In progress — currently setting up the frontend.
Planned Features
View list of tasks
Add a new task
Mark a task as done
Delete a task
Connect frontend to backend via API
Store tasks in a SQL database

  About
This project is part of my journey learning software development — combining what I've studied separately (HTML/CSS, C#, SQL) into one full-stack application.
